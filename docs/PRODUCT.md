# Product

## Register

product

## Users

Adaptive Skills serves developers and heavy users of local coding agents who maintain reusable Skills across multiple repositories and Agent runtimes. They need to discover what already exists, assess provenance and risk, curate a local catalog, and install only the right Skills into a project or an Agent-wide directory.

## Product Purpose

Adaptive Skills is the local control plane for the Skill lifecycle: discover, collect, scan, classify, evaluate, compare, and explicitly mount Skills into ordinary projects or global Agent scopes. Success means users can understand where every Skill came from, what state it is in, and exactly which filesystem changes an action will make.

## Brand Personality

Precise, trustworthy, local-first. The interface should feel calm and operational, with enough density for expert work and clear language at every destructive or ownership-changing boundary.

## Anti-references

- Generic “AI magic” dashboards that conceal provenance or imply the model is always correct.
- Decorative analytics, excessive cards, or motion that competes with catalog and filesystem state.
- Ambiguous install, delete, replace, or unlink actions that do not distinguish Adaptive-managed content from external content.
- Cloud-first account patterns that undermine the product’s local-first trust boundary.

## Design Principles

1. Make ownership visible: distinguish catalog source, external content, managed links, and system-owned mappings at a glance.
2. Explain filesystem effects before acting: installation, replacement, unlinking, and synchronization must name their target and recovery boundary.
3. Preserve user work by default: external content is read-only until the user explicitly links or replaces it.
4. Keep expert workflows compact: expose status, provenance, risk, and the next valid action without decorative detours.
5. Keep intelligence accountable: AI classification and scoring are proposals or evidence, never hidden authority.

## Accessibility & Inclusion

Meet WCAG AA contrast expectations for text and controls, preserve complete keyboard navigation and visible focus states, avoid color-only status communication, and respect reduced-motion preferences. Chinese interface copy must remain concise and unambiguous at filesystem mutation boundaries.
